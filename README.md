# Laboratory Activity: Recursion

## Brief Description
This Java program uses recursion to draw a text-based ruler in centimeters. It recursively generates centimeter markings and subdivisions, displays the equivalent measurement in inches, and shows a recursion trace. The program also accepts a user-entered ruler length.

## Programming Language
Java

## How to Compile and Run
1. Open a terminal or command prompt in the folder containing `RecursiveRuler.java`.
2. Compile:
   `javac RecursiveRuler.java`
3. Run:
   `java RecursiveRuler`
4. Enter a non-negative whole-number length in centimeters.

## Sample Input
```text
10
```

## Sample Output
```text
10-cm recursive ruler
--------------------------------
-------- 0 cm
----
--
---
-
--
---
----
...
-------- 10 cm
Equivalent length: 3.94 inches
```

The actual program also displays the complete recursive subdivisions and recursion trace.
